This demo stays in-repo as the reference implementation for the chapter’s UMAP projection exercise.

## Status

## Intended flow
1) Extract hidden-state embeddings from a chosen model layer.
2) Run UMAP to project embeddings to 2D.
3) Visualize clusters by token/label family.
4) Compare early vs late layers.
