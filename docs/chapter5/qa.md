# Chapter 5 Q&A - AlexNet & Scale

## Exercise 5.1
**How was AlexNet different than most other computer vision approaches at the time?**

AlexNet was revolutionary because it:
1. Used deep learning instead of hand-crafted features (SIFT, HOG, etc.)
2. Trained on GPUs - first major use of CUDA for neural network training
3. Used ReLU activation instead of tanh/sigmoid, enabling much faster training
4. Applied dropout for regularization, a novel technique at the time
5. Was end-to-end trainable - learned features directly from raw pixels

Prior approaches relied on domain experts manually designing feature extractors. AlexNet learned these features automatically from data.

## Exercise 5.2
**Figure 5.3 shows how large language models like ChatGPT answer questions. What makes this process inefficient? How might we speed up this process?**

The inefficiency is autoregressive generation:
- To generate N tokens, the model runs N separate forward passes
- Each pass processes the ENTIRE sequence so far (quadratic attention)
- Only the LAST column of output is used to predict the next token

Speedup approaches (covered in Chapter 8):
1. KV-caching - Cache key/value matrices, avoid recomputation
2. Speculative decoding - Use small model to draft, large model to verify
3. Parallel decoding - Predict multiple tokens at once
4. Quantization - Reduce precision (FP16, INT8, INT4)
5. Pruning - Remove less important attention heads/layers

## Exercise 5.3
**Why is AlexNet's input data dimension 224x224x3? Why is its output dimension 1x1000?**

Input (224x224x3):
- 224x224 - Chosen image resolution (balance between detail and compute)
- x3 - RGB color channels (Red, Green, Blue)

Output (1x1000):
- 1000 - Number of ImageNet classes (dog breeds, vehicles, objects, etc.)
- Each output neuron represents probability of one class
- Softmax converts to probability distribution summing to 1

The network compresses 224x224x3 = 150,528 input values into 1000 class probabilities.

## Exercise 5.4
**Why is it easier to visualize what's happening in the first layer of AlexNet, compared to other layers?**

First layer filters operate directly on raw RGB pixels, making them interpretable as:
- Edge detectors (horizontal, vertical, diagonal)
- Color blob detectors
- Gabor-like patterns

These are similar to what neuroscientists found in V1 (primary visual cortex).

Deeper layers combine these simple patterns into abstract compositions:
- Layer 2: Corners, textures, simple shapes
- Layer 3-5: Object parts, faces, wheels, text

These higher-level features do not map to simple visual patterns.

**Figure 5.10 shows the outputs of the second layer of AlexNet. We found that feature map 104 appears to be a corner detector - do you see other feature maps that appear to be responding to specific features?**

Common patterns found in Layer 2:
- Texture detectors - Repeating patterns, gradients
- Corner detectors - L-shapes, T-junctions
- Color gradient detectors - Smooth color transitions
- Edge orientation combiners - More complex edge patterns

Each filter combines multiple Layer 1 edge detectors to form more complex patterns.

## Exercise 5.6
**Figure 5.12 shows the outputs of the fifth layer of AlexNet. We found that feature map 186 appears to be a face detector - do you see other feature maps that appear to be responding to specific features?**

Layer 5 (final conv layer) contains high-level semantic detectors:
- Face detectors - Respond to face-like arrangements
- Text detectors - Respond to written text patterns
- Wheel detectors - Circular patterns with spokes
- Animal body part detectors - Eyes, ears, paws
- Scene detectors - Sky, grass, water textures

These are grandmother cells - neurons that respond to specific semantic concepts.

## Exercise 5.7
**What interesting properties did Hinton's team notice about the vectors generated by the second to last layer of AlexNet (Figure 5.15)?**

The penultimate layer (FC7, 4096-dim) embeddings showed:
1. Semantic clustering - Similar objects cluster together in embedding space
2. Vector arithmetic - Meaningful relationships preserved
3. Transfer learning - Features generalize to other tasks
4. Interpolation - Smooth transitions between object categories

This was early evidence of learned representations capturing semantic meaning.

## Exercise 5.8
**What is an activation atlas?**

An activation atlas is a visualization technique that:
1. Runs thousands of images through a neural network
2. Collects activation vectors from a specific layer
3. Projects them to 2D using dimensionality reduction (UMAP/t-SNE)
4. Places representative image patches at each location
5. Creates a map of what the network has learned

The atlas shows semantic organization, feature space structure, and the network's internal representation of visual concepts. Developed by Carter et al. at Google Brain (2019).

## Exercise 5.9
**The underlying algorithms for creating and training AlexNet existed long before 2012 - what took so long?**

Three key enablers converged around 2012:

1. Data - ImageNet (14M+ labeled images) released 2009
2. Compute - NVIDIA GPUs with CUDA (10-50x faster than CPU)
3. Techniques - ReLU, dropout, data augmentation

The algorithms (backprop, CNNs) existed since 1980s-1990s, but lacked these three ingredients.

**How many more parameters does GPT-3 have than AlexNet? What about GPT-4?**

Model comparison:

## Exercise 5.11
**Do you think the next set of AI breakthroughs will be driven by more scaling of existing approaches (i.e., more data, compute), or will fundamentally new ideas be required?**

This is an open debate in AI research:

Arguments for scaling:
- Scaling laws show predictable improvement with more compute
- GPT-4, Claude, Gemini all benefit from scale

Arguments for new ideas:
- Diminishing returns at extreme scales
- Current models lack reasoning, planning, world models
- Energy/cost constraints make infinite scaling impractical

Likely answer: Both. New architectures create step-changes, then scaling improves them.
