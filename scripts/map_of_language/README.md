# Map of Language (Scaffold)

This directory will hold the scripts for the Chapter 3 Map of Language demo.

## Planned steps
1) Extract hidden-state embeddings for a chosen model layer.
2) Run UMAP to project embeddings to 2D.
3) Plot clusters by token/label family.
4) Compare early vs late layers.

## Notes
- This scaffold intentionally keeps heavy dependencies out of the main repo.
- Scripts will be added once the final model/source is chosen.
